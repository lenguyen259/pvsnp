# L-meta-612, route T4: partial suns (C4-free pseudoforests)

Status: **NOT closed** for all pseudoforests. New results:
* **PROVED (Lemma R2, any graph, any circuit).** A counting bound for x_S := 1 that needs only one
  OR reader per vertex of S. With it, **no full sun is a minimal counterexample.** A full sun is a
  cycle with a pendant at every vertex, and the same holds for any disjoint union of full suns and bare
  cycles. This is an infinite family, and it includes the net and sun5.
* **PROVED.** In a minimal pseudoforest counterexample, every *run* (a maximal path of cycle vertices
  without a pendant) has even length. There are m >= 1 runs, and the all-pendants option has
  deficit exactly m.
* **SAT (conditional on the PROVED min-cex structure).** C5{012}, C6{01} and C6{03} (8 vertices)
  are not minimal counterexamples. The 10-vertex partial suns time out after 1 h.
* **SAT (unconditional).** Every size <= Phi - 2 is excluded for all three 8-vertex graphs. See §3
  for size Phi - 1.

Labels are as in t2/t3: PROVED, DATA, REFUTED. "min cex" means a minimal C4-free pseudoforest
counterexample G with a minimum circuit C, s = Phi(G) - 1, and the claim holding for every proper
induced subgraph (t2 Corollary M, t3 Theorem L). By t3, G is a disjoint union of cycles (C3 or
C_n with n >= 5) with at most one pendant per cycle vertex. Every pendant v at u has δ_v = 1 and
deg u = 3. x_v has a single reader g_v = x_v ∨ z_v (an OR gate), and g_v has a single reader q_v
(an AND gate). F_u = 1.

## 1. Lemma R2 (PROVED, any G, any circuit C)

Let S be an independent set, put e_S = indicator of S, R = {gates p : p(e_S) = 1}, and ∂R = {AND gates
not in R with an input in R ∪ x_S}. Let r1 be the number of gates of R with exactly one input in
R ∪ x_S. Then
  elim(x_S := 1) >= |R| + |∂R| >= |S| + r1.
In particular, elim(x_S := 1) >= |S| + #{w ∈ S : x_w has an OR reader x_w ∨ z with z(e_S) = 0}.

*Proof.* Gates of R become constant 1, and gates of ∂R become copies of their other input, so all
are eliminated (t2 §0). Every node of x_S ∪ R has a reader, because every gate reaches the output
and f depends on x_w. Every reader of such a node lies in R ∪ ∂R: an OR reader, or an AND reader
whose other input is in R ∪ x_S, has value 1 at e_S; any other AND reader is in ∂R. Every gate of R
has an input in R ∪ x_S, since the only variables equal to 1 at e_S are x_S. A gate of ∂R has
exactly one such input, otherwise it would lie in R.

Count the arcs from x_S ∪ R into R ∪ ∂R from the reader side. They number |R| + r2 + |∂R|, where
r2 counts the gates of R with two such inputs. Every node of x_S ∪ R sends at least one arc, so
|R| + r2 + |∂R| >= |S| + |R|, that is r2 + |∂R| >= |S|. Hence |R| + |∂R| = r1 + r2 + |∂R| >= r1 + |S|.

Each OR gate x_w ∨ z with z(e_S) = 0 is in R and has exactly one R-input, namely x_w. So it is
counted in r1, and different w give different gates. ∎

Check (`chkR.py`): 9,559 locpool circuits in which every pendant has a single OR reader. In all of
them z_v(e_P) = 0 and |R| + |∂R| >= 2|P| hold, with 0 violations.

**Corollary (PROVED).** In a min cex, let P be the set of all pendants. Then z_v(e_P) = 0 for every
v ∈ P, and so elim(x_P := 1) >= 2|P|.

*Proof of z_v(e_P) = 0.* z_v does not depend on x_v. Suppose z_v(e_P) = 1. Then
g_v(e_{P-v} + e_u) = 1 = g_v(e_{P-v} + e_u + e_v). Since x_v is read only by g_v, the output is the
same at both inputs. But f(e_{P-v} + e_u + e_v) = 1 and f(e_{P-v} + e_u) = 0: the only pendant at u is
v, and the pendants are pairwise non-adjacent. Contradiction. ∎

## 2. The all-pendants option rho_P = (∅, P)

Let U be the set of pendant holders and H = G - P - U. H consists of the bare cycle components and,
inside each cycle that has pendants, its *runs* (maximal paths of bare cycle vertices).
f|rho_P = OR_U ∨ f_H.

**need formula (PROVED).** Let m be the number of runs. Then need(rho_P) = 2|P| + m.

*Proof.* Take a component K = C_n with k_K pendants and runs of lengths l_i. The pendant edges
together with a maximum matching of each run form a matching, and U plus a minimum cover of each
run is a cover. So tau(K) = k_K + Σ floor(l_i/2). Also n = k_K + Σ l_i, and run i has l_i - 1 edges.
Substituting into Phi(G) - |U| - Phi(H) (which includes the edgeless convention
LB = |F| - 1), everything cancels except Σ_K (2 k_K + #runs_K). ∎

**Theorem P1 (PROVED).** A min cex has m >= 1. Equivalently, no disjoint union of full suns
(C3 = net, C5 = sun5, C_n with all n pendants) and bare cycles is a minimal counterexample.

*Proof.* If m = 0, then elim(rho_P) >= 2|P| = need(rho_P), so rho_P is a good option. This
contradicts R-TOT-G (t3 §0). ∎

**Runs are even (PROVED).** Let v be a pendant at u, and let a run of length l be adjacent to u.
Since δ_v = 1, some minimum cover contains v and not u. By the tau formula, such a cover uses exactly
floor(l/2) vertices of the run, while still covering the edge from u to the run. That is impossible
when l is odd. Every run is adjacent to a holder, so every run has even length. This matches
`psun.py`'s list.

**Tightness for m = 1 (PROVED).** Here rho_P is bad, so elim(rho_P) = 2|P| exactly. All the
inequalities of Lemma R2 are therefore equalities:
* R_P = {g_v}, and ∂R_P = {q_v}, all distinct;
* red(C|rho_P) = C - {g_v, q_v} (with q_v replaced by y_v) is a minimum circuit for OR_U ∨ f_H;
* every OR gate x_w ∨ z with z(e_P) = 1 is some g_v.

**Lemma Ψ (PROVED, used for runs).** Let w_1 be a run end adjacent to u, let v be the pendant at u,
and let w_2 be the other neighbour of w_1. If x_{w_1} were read only by g_v (that is, z_v = x_{w_1}),
then every path from x_v and from x_{w_1} would pass through q_v. Now f(e_{w_1} + e_{w_2}) = 1 forces
y_v(e_{w_2}) = 1, so q_v = 1 at both e_{w_1} + e_{w_2} and e_v + e_{w_2}. All other inputs of the
output's dependence on q_v agree at these two points, yet f = 1 at the first and f = 0 at the second.
This is impossible. Hence, for m = 1, an OR reader of x_{w_1} with z(e_P) = 1 can exist only when
F_{w_1} = 2.

**The bare-run options rho_{P∪B} (structure, PROVED arithmetic).** For every partial sun on <= 9
cycle vertices (`rhoP3.py`), there is an independent set B of run vertices (floor(l/2) per run) with
need(x_{P∪B} := 1) = |P ∪ B| + |P| + |B|. By Lemma R2, this option is good as soon as every v ∈ P and
every w ∈ B has an OR reader whose other input is 0 at e_{P∪B}. Only a pendant whose holder is
adjacent to B can fail this, and the bad cases at a run vertex w are: (a) x_w has a single AND
reader; (b) every OR reader x_w ∨ z of x_w has z(e_{P∪B}) = 1. Closing (a) and (b) is the exact
remaining gap (§4).

## 3. SAT base cases

Encoder `enc5.py`, adapted from pet19/enc3.py. It uses the monotone test set (edge rows = 1,
maximal independent sets = 0), pair selectors, depth-canonical topological order with lex
tie-breaking, AND before OR for equal pairs, all gates used, and pairwise distinct gate functions on
the test rows. Optionally it adds the associativity chain normal form. All of these are sound for
the minimum-size circuit. Solver: CaDiCaL 1.9.5 via pysat, one process at a time.

* *Unconditional* runs: no circuit with exactly s gates, for each s up to Phi - 1. Since a minimum
  circuit satisfies every constraint at its own size, UNSAT for all s <= Phi - 1 proves the claim
  for that graph.
* *Conditional* runs (`--mincex --opts`) add only PROVED properties of a min cex:
  - s = Phi - 1;
  - each pendant has exactly one reader, an OR gate, whose only reader is an AND gate
    (Corollary M, Theorem L(b));
  - F_u = 1 at each holder;
  - elim(rho) <= need(rho) - 1 for the options A, B, N and N' at every vertex, for every subset of
    pendants set to 1, and for all (S0, S1) with |S0|, |S1| <= 3 and need <= 4.

  elim is encoded as a sound under-count: the gates with a constant input, plus the gates whose
  every reader is constant or dead. UNSAT means G is not a min cex, which is what the induction needs.
* Soundness checks: 8 random locpool circuits on C5{012}, fixed into the encoding with bounds equal
  to their true elim, all SAT (`sanity.py`); 4 circuits with the min-cex reader structure on C6{01},
  fixed with `--mincex`, all SAT (`sanity2.py`). The non-vacuity check is listed below.

All runs are logged in `sat.log`. Times are wall-clock seconds, CaDiCaL 1.9.5, one process.

## 4. Exact gap

The full claim for C4-free pseudoforests now reduces (PROVED) to excluding minimal counterexamples
of the following form:
* a disjoint union of cycles with pendants;
* m >= 1 bare runs, all of even length;
* every pendant has the t3 Theorem L shape, so elim(rho_P) <= 2|P| + m - 1;
* the smallest such graph is not one of the SAT-excluded graphs of §3.

The first open graphs are the 10-vertex partial suns C6{0123}, C7{012} and C7{014} (SAT timed out)
and C8{01} and C8{03} (not run),
then the larger ones: C7{01234}, C8{0123}, and so on, plus unions such as
net + C5{012}. Since this list is infinite, SAT alone cannot close the problem. A proof for
general m needs one extra eliminated gate per run, beyond Lemma R2's 2|P|. The natural candidates
are the options x_{P∪B} := 1 of §2, which need only the two bad cases (a) and (b) at run vertices to
be excluded. Lemma Ψ excludes the simplest form of (b) when m = 1.
REFUTED as proof routes (locpool circuits that have the full min-cex reader structure, `dataP2.py`):
"elim(rho_P) >= need(rho_P)" and "elim(U := 0, P := 1) >= need" both fail. The smallest instance is
C6{01} at size Phi + 2, with deficit -1:
`8=3&4 9=3&2 10=0|9 11=7|2 12=10|4 13=12&5 14=1|9 15=6|14 16=11&14 17=15&10 18=16|13 19=17|8 20=19|18`.
So any proof must use the global badness of a min cex, not only the local reader structure.
