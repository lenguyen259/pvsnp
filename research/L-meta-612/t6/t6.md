# L-meta-612, route T6: partial suns, insertion structure, SAT base cases

Status: **NOT closed** for all C4-free pseudoforests. New results:
* **PROVED (Lemma INS).** In a min cex, contracting every pendant gate g_v := z_v turns C into a circuit
  C' for f_{G-P} (disjoint cycles) with |C'| = Phi(G-P) + Σ_K floor(k_K/2) - 1 (k_K = number of pendants
  on cycle K). When G has one pendant component with k = 2 or 3 pendants, C' is a **minimum** circuit for
  f_{C_n}, and C is C' with x_v OR-ed into one input of one AND gate, once per pendant.
* **SAT (conditional on PROVED facts only), new encoder `enc6.py`** built on INS:
  C6{0123}, C7{012}, C7{014} and C8{01} are **not** minimal counterexamples (UNSAT in 34 s, 223 s, 244 s and 811 s). C8{03} timed out (2 × 1 h) and remains open.
  The 8-vertex cases re-check in 1-9 s (was 76-98 s).
* **PROVED (item 7 need formula, all partial suns).** For every choice of a maximum independent set B_r
  (|B_r| = l_r/2) in every run r: need(x_{P∪B} := 1) = 2|P| + 2|B| = |P∪B| + |P| + |B|.
* **PROVED (Lemma PN, any graph, any circuit).** If every reader of x_w is an OR gate x_w ∨ z_i and w
  has a *private neighbour* w' w.r.t. an independent S ∋ w (N(w') ∩ S = {w}), then z_i(e_S) = 0 for some i.
  So item 7's bad case (b) is impossible at every vertex of S with a private neighbour.
* **PROVED (Lemma AT).** If x_w has a single reader, an AND gate a = x_w ∧ c ("AND-type" w, item 7's
  bad case (a)), then every gate is 0 at e_w, c(e_{w'}) = 1 for all w' ∈ N(w), and two adjacent vertices are
  never both AND-type. In a min cex, a run vertex w that is AND-type has the dual gadget
  x_w → a = x_w ∧ c → b = a ∨ d (single readers each).
* Not proved: the two bad cases of item 7 in general (exact residual gap in §4).

Labels: PROVED (full proof here), DATA (machine check only), SAT (solver result on an encoding whose
every clause is a PROVED property of a min cex), REFUTED. "min cex": G a minimal C4-free pseudoforest
counterexample, C a minimum circuit, s = |C| = Phi(G) - 1 (t2 Cor M). By t3/t4, G is a disjoint union of
cycles with at most one pendant per cycle vertex; pendant v at holder u: δ_v = 1, deg u = 3, x_v → g_v =
x_v ∨ z_v → q_v = g_v ∧ y_v (single readers), F_u = 1, z_v ≠ x_u, z_v(e_u) = 0, y_v(e_u) = 1; runs even.

## 1. Proved lemmas

**Need formula for item 7 (PROVED, every partial sun and union with bare cycles).** Let a run be the path
w_1 ... w_{2j} and B_r any independent set of size j in it. Then B_r ∪ N(B_r) is the whole run (if w_i had no
B-neighbour and w_i ∉ B_r, then B_r would lie in two paths of i-2 and 2j-i-1 vertices, which hold at most
j - 1 independent vertices). So with S1 = P ∪ B: F = U ∪ (runs \ B), and H = the bare cycles. A pendant
component K with k pendants and run total L has |E_K| + τ_K = (2k + L) + (k + L/2), and contributes
k + L/2 to |F|. The -1 conventions cancel as in t4. Hence need = Σ_K (2k_K + L_K) = 2|P| + 2|B|. ∎
(Any other B, e.g. one vertex per run, gives need >= 2|S| + 1 per run: `needs6.py`, `mix.py`.)

**Lemma PN (PROVED, any G, any circuit).** Let S be independent, w ∈ S, and let all readers of x_w be OR
gates h_i = x_w ∨ z_i (i = 1..r, in topological order). If some w' ∈ N(w) has N(w') ∩ S = {w}, then
z_i(e_S) = 0 for some i.
*Proof.* Suppose z_i(e_S) = 1 for all i. Put a' = e_{S-w}. A path from x_w to z_i passes through some h_j
with h_j < z_i < h_i, so j < i. By induction on i, h_j(a') = 1 = h_j(e_S) for j < i, so every node feeding
z_i has the same value at a' and at e_S, hence z_i(a') = 1 and h_i(a') = 1. Let a = a' + e_{w'} and
b = a + e_w. By monotonicity all h_i equal 1 at a and at b, and x_w reaches the output only through the
h_i, so out(a) = out(b). But a is independent (w' has no neighbour in S - w), so f(a) = 0, while f(b) = 1. ∎
Special cases: t4's z_v(e_P) = 0; and, for a pendant v, **z_v(I) = 0 for every independent I with
I ∩ N[u] = ∅** (take S = I + v; used in `enc6.py` as the `zr` rows).

**Lemma AT (PROVED, any G, any circuit).** Let x_w have a single reader a = x_w ∧ c. Then c does not depend
on x_w, a(e_w) = c(0) = 0, so every node other than x_w is 0 at e_w. For w' ∈ N(w): f(e_w + e_{w'}) = 1 and
f(e_{w'}) = 0 force a(e_w + e_{w'}) = 1, so c(e_{w'}) = 1. If w' were also of this type, c would need
c(e_w) = 1, impossible. So AND-type vertices are pairwise non-adjacent. In a min cex, for a run vertex
(need_A = 3) A(w) is bad, so |D_w| + |∂D_w| <= 2. With a ∈ D_w and the Reader-Lemma exit in ∂D_w, this
gives D_w = {a}, and a has exactly one reader b = a ∨ d (OR). This is the dual of the pendant gadget. ∎

**Lemma INS (PROVED).** Let G, C be a min cex, P the set of pendants, and C' = C with every g_v replaced by
z_v (|C'| = s - |P|). Then C' computes f_{G-P}. By Theorem F2, |red(C')| >= Phi(G-P), and
Phi(G) - Phi(G-P) = |P| + Σ_K floor(k_K/2) (τ drops by k + L/2 - ceil((k+L)/2) = floor(k/2) per
component, since L is even). So C' has at most Σ_K floor(k_K/2) - 1 redundant gates. If this sum is 1
(one pendant component, k ∈ {2,3}), C' is reduced and minimum for f_{C_n}. Conversely, C is C' plus, for each v,
the OR gate x_v ∨ z_v inserted on the wire z_v → q_v of the AND gate q_v. Distinct pendants use distinct
(gate, side) wires (g_v cannot read g_{v'}, and z_v is never a pendant: sing(z_v) ⊆ N(u) - v). ∎
More generally, for any pendant set P' with τ(G) - τ(G-P') = 1, C with g_{P'} contracted is a minimum
circuit of G - P'.

## 2. Item 7 status (the two bad cases)

S = P ∪ B with need 2|S|. By Lemma R2, the option is good as soon as every s ∈ S has an OR reader x_s ∨ z
with z(e_S) = 0. By Lemma PN this holds for every s ∈ S that has only OR readers and a private neighbour.
* Pendants have only OR readers. So a pendant fails only if its holder has a B-neighbour.
* Run vertex w ∈ B: case (b) (only OR readers, all with z(e_S) = 1) is **impossible** when w has a private
  neighbour (PROVED). With B_i = {w_1, w_3, .., w_{2i-1}, w_{2i+2}, .., w_{2j}}, the vertices with private
  neighbours are w_{2i-1} and w_{2i+2} (and w_2 for i = 0, w_{2j-1} for i = j). So every vertex of B has one
  when the run has length 2 or 4, but not the interior B-vertices of longer runs.
* Case (a) (AND-type w ∈ B): not excluded. AND-types are independent (Lemma AT), but a run of length 4 with
  AND-types {w_1, w_4} meets every maximum B.
* Unavoidable loss: some pendant always has a B-neighbour at its holder, because |B_r| = l/2 forces w_1 or w_{2j}
  into B. There g_v and q_v are still eliminated (g_v ∈ R, q_v ∈ R ∪ ∂R), but R2's count loses 1 when
  z_v(e_S) = 1. So R2 + PN alone can never certify P ∪ B (PROVED by this counting; it is not a refutation of
  P ∪ B itself).
DATA: on all 661 locpool circuits with the full min-cex reader structure (C6{01}, C6{03}), some P ∪ B option
is good (`an1.py`); the cycle-shortening substitutions (x_w := x_b, x_{w'} := x_a, need 3) are never good on
them, and are invalid (they create C4) on the 6-cycles.

## 3. SAT base cases (`enc6.py`, log `sat6.log`)

Encoding = INS: C' (s - |P| gates on the cycle variables) plus insertion variables ins(v, gate, side). Every
clause is PROVED for a min cex:
1. s = Phi - 1; one insertion per pendant, on an AND gate, distinct wires (Cor M, Thm L(b), INS);
2. `--cnd` (only when Σ floor(k/2) = 1): C' minimum for f_{C_n}, hence pairwise distinct and nonconstant on
   the C_n test rows (INS + F2; merging two gates equal on the test set gives a smaller monotone circuit that is
   correct on the test set, hence everywhere);
3. C' gates pairwise distinct and nonconstant on the G test rows (C is minimum), and all gates are used;
4. depth-canonical order on C' (sort layer by layer; equal (pair, op) is allowed, since insertions may differ);
5. holders: exactly one reader of x_u in C (counting g_{v'} when z_{v'} = x_u), z_v ≠ x_u, z_v(e_u) = 0,
   y_v(e_u) = 1 (Thm L);
6. z_v = 0 on all maximal independent sets of G - N[u] (Lemma PN);
7. run vertices: F_w + min(k_and, 2) <= need_A - 1 = 2 and F_w + min(k_or, 2) <= need_B - 1 (Cor M.4),
   counted in C.

Soundness checks: (i) `xcheck3.py`: 300 locpool circuits × 4 fact groups, fixed into the encoding (without
canonical order): the encoding accepts a circuit exactly when an independent Python check says the facts hold.
That is 0 mismatches, 278 of them with z_v a cycle input. (ii) `canonchk.py`: 150 circuits re-ordered by the
layer sort, fixed with canonical order on: all SAT. (iii) Non-vacuity: C6{01} at s = 12 is SAT and verified on
all inputs; C6{02} (τ unchanged by its pendants, Phi = 10) at s = 10 with `--cnd` is SAT. (iv) An earlier
version double-counted a reader at an inserted wire. Its results are void and are marked as such in `sat6.log`.

## 4. Exact remaining gap

PROVED reduction (t3, t4, this note): a minimal C4-free pseudoforest counterexample is a union of cycles with
pendants, m >= 1 even runs, the gadget structure above, and C = C' + insertions with |C'| <=
Phi(G-P) + Σ floor(k_K/2) - 1. It is not in the SAT-excluded list above. Open:
* **Infinite families.** Single-component k ∈ {2,3} (C_n{01}, C_n{03}, C_n{012}, ... for n >= 8): these reduce to
  "no minimum circuit of C_n admits 2 (or 3) valid AND-wire insertions at holders whose pendants raise τ by 1".
  This needs a structure theory of minimum circuits for f_{C_n}, which is not available.
* **Item 7.** The proof needs, per run, one gate beyond R2 + PN: at AND-type B-vertices (case (a)), at
  interior B-vertices of runs of length >= 6 (no private neighbour, case (b) open), and at the pendant whose
  holder touches B (z_v(e_S) = 1 possible). The candidate is the dual gadget of Lemma AT (a, b both die
  under x_w := 0). The mixed options x_{A0} := 0, x_{P∪A1} := 1 have need 1.5 per assigned run vertex
  (`mix.py`), but no counting lemma combining the D- and R-sides was found.
