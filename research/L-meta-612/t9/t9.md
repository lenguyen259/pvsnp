# L-meta-612, route T9: the AND/OR split. The claim holds for all C4-free pseudoforests

Status: **PROVED** for every C4-free pseudoforest G with an edge: every monotone fan-in-2 circuit C for
f_G has **#AND(C) >= tau(G)** (new here) and **#OR(C) >= |E| - 1** (accepted Lean `L_meta_599`). Hence
|C| >= |E| + tau(G) - 1. This closes the route of t3-t6 completely. Its special cases include the requested
insertion impossibility (every n, every k, single or several components), C8{03}, and bare cycles.
Caveat: the OR half is the Lean theorem as stated in
`brilliant-hq/pequalnp-proofs/lean/PEqualNP/Outside/L_meta_599.lean`. or.md calls it accepted. I read its
statement but did not re-run Lean (not allowed in this task). The AND half is a hand proof (§1-§2) with
DATA checks. Have it red-teamed before it is published anywhere.

Labels: PROVED (full proof here), DATA (machine check), REFUTED (smallest instance).
Circuits are monotone, fan-in 2, with inputs x_1..x_n and no constants. alpha(G) = least #AND over all
circuits for f_G, with alpha = 0 for edgeless G. "x := c removes an AND gate" means: after constant
propagation, the AND-gate count drops by >= 1 (propagation and dead-gate removal never add gates).

## 0. The split

**(OR) (PROVED, Lean L_meta_599).** If G is a pseudoforest (every S spans <= |S| edges) with no 4-cycle,
then |E| <= #OR(C) + 1 for every Monotone2 circuit C computing f_G.

So it suffices to prove **(AND): alpha(G) >= tau(G) for every C4-free pseudoforest.**

## 1. Two restriction lemmas (any graph)

**Lemma X1 (PROVED).** If the output depends on x_v and f|_{x_v=1} is not constant 1, then x_v := 1
removes an AND gate.
*Proof.* Drop dead gates. Some reader r0 of x_v is on a path to the output. If r0 is an AND gate x_v ∧ c,
it becomes a copy of c. If r0 is an OR gate, follow the path. An OR gate with a constant-1 input becomes 1.
The output is not constant 1, so the first gate on the path that does not become 1 is an AND gate with a
constant-1 input. It becomes a copy of its other input. ∎

**Lemma AL (PROVED, leaf).** For a leaf v with neighbour u: alpha(G) >= 1 + alpha(G - u - v), and
tau(G - u - v) = tau(G) - 1.
*Proof.* f|_{x_v=1} = x_u ∨ f_{G-v} is not constant 1, so X1 removes an AND gate. Then x_u := 0 gives
f_{G-u-v}. For the tau fact, some minimum cover contains u (swap v for u). ∎
Hence **alpha >= tau for every forest** (Theorem AND-F).

## 2. The leafless case: Lemma AND-core (PROVED)

Notation: Q_v is the set of gates that become constant 1 under x_v := 1. Inductively, it holds the OR gates
with an input in {x_v} ∪ Q_v and the AND gates with both inputs there. Ex(v) is the set of AND gates
outside Q_v with an input in {x_v} ∪ Q_v (the exits). Under x_v := 1 every exit becomes a copy, so
x_v := 1 removes >= |Ex(v)| AND gates.

**Lemma AND-core.** Let G be C4-free, every non-isolated vertex of degree >= 2, and C a circuit for f_G
without dead gates. Then some non-isolated v satisfies (a) x_v has an AND reader, or (b) |Ex(v)| >= 2.

*Proof.* Suppose not. Then every non-isolated v has only OR readers and exactly one exit
E(v) = s_v ∧ t_v, with s_v ∈ Q_v. Ex(v) is non-empty by the argument of X1. Note t_v ∉ Q_v ∪ {x_v}.
1. *Every path from x_v to a node outside Q_v ∪ {x_v} passes through E(v), entering at s_v.* The first node
   off Q_v on such a path is an exit. Consequently t_v does not depend on x_v. Cut E(v) out as a free value
   e: the output O(e, x) does not depend on x_v either. Also s_v = x_v ∨ σ_v as functions, and
   f(x) = O(E(v)(x), x).
2. *For a ∈ N(v): E(v)(e_a) = 0 and t_v(e_a) = 1.* We have f(e_a) = 0 and f(e_a + e_v) = 1, and O
   ignores x_v.
3. *If t_v ∈ Q_a, then E(a) = E(v), with t_v on a's side.* E(v) ∉ Q_a, because E(v)(e_a) = 0.
4. *If t_v ∉ Q_a, then E(a) comes before E(v).* t_v depends on x_a by step 2, and t_v ≠ x_a since there is no
   AND reader. Step 1 for a puts E(a) on a path from x_a to t_v.
5. *Two vertices never share a side of one exit.* Suppose a1 ≠ a2 both enter E = s ∧ t at s. Then, in the
   coordinates (x_{a1}, x_{a2}), f(1,0,y) = f(1,1,y) = f(0,1,y) = O(t(y), y). If a1 ~ a2, then
   f(1,1,0) = 1 ≠ 0 = f(1,0,0). Otherwise y = e_b gives N(a1) = N(a2), and both have degree >= 2. That is
   a C4.
Now let v have the earliest exit, with neighbours a1 ≠ a2. Steps 3 and 5 forbid t_v ∈ Q_{a1} ∩ Q_{a2}. So by
step 4 some E(a_i) comes before E(v). Contradiction. ∎

## 3. Theorem PF (PROVED)

**alpha(G) >= tau(G) for every C4-free pseudoforest G**, and therefore |C| >= |E| + tau(G) - 1.
*Proof.* Induction on |V| in the class, which is closed under vertex deletion. If there is a leaf, use
Lemma AL. Otherwise every edge lies in a 2-regular component C_3 or C_n with n >= 5, and Lemma AND-core
applies.
* (a) x_v := 0 kills the AND reader, and tau(G - v) >= tau(G) - 1.
* (b) x_v := 1 kills two exits, then x_{N(v)} := 0 leaves f_{G - N[v]}, and
  tau(G - N[v]) >= tau(G) - |N(v)| = tau(G) - 2. ∎

Corollaries (all PROVED):
* **The requested insertion impossibility, in full.** For n >= 5 and any pendants on C_n whose holders lie
  in no common minimum cover, no circuit of size Phi(C_n) for f_{C_n} admits insertions giving f_G. The
  same holds with several components: no Σ floor(k_K/2) bookkeeping is needed. Directly: a min cex would
  have #OR >= |E| - 1, hence #AND <= tau(G) - 1. But x_{v_1} := 1, x_{u_1} := 0 kills an AND gate and leaves
  a tree.
* **C8{03}, C8{01} and every partial sun are not counterexamples.** No SAT is needed.
* **Minimum circuits of C_n** have exactly ceil(n/2) AND gates and n - 1 OR gates. DATA agrees: (3,4) on
  all 25 minimum C5 circuits, (3,5) on all 6 for C6, (4,6) on 35 for C7.
* Theorem F2 (t2) and t3's and t4's base cases are special cases.
* Outside pseudoforests: AL and AND-core hold for any C4-free graph. Induction stalls only when AND-core
  returns a vertex of degree >= 3 with two exits (need deg v > 2). (OR) is false in general (Petersen,
  t2), so this route is specific to pseudoforests.
