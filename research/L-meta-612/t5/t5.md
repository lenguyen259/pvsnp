## 1. PROVED

**Lemma C2 (structure; any reduced C).** Let g = x_a ∧ x_b with ab ∈ E, let G - a have an edge, and let
A(a) be bad. Then F_a + min(k_and(a), 2) <= deg a + δ_a - 1. In particular F_a >= 2 forces
deg a + δ_a >= 4. If in addition deg a = 3, then:
* δ_a = 1;
* x_a has exactly two readers, g and one OR gate p_a = x_a ∨ z_a;
* g has exactly one reader, an OR gate r = g ∨ y with y ≰ x_a;
* elim(a,0) = 3, the eliminated gates are exactly {g, p_a, r}, and red(C|x_a=0) is C with g deleted,
  p_a replaced by z_a and r replaced by y. In a min cex this is a minimum circuit for f_{G-a}.

*Proof.* need_A(a) = deg a + δ_a, so A(a) bad gives elim(a,0) <= deg a + δ_a - 1. The Reader Lemma (a)
gives the first inequality. Now let deg a = 3. Then 3 <= F_a + min(k_and, 2) <= 2 + δ_a, so δ_a = 1,
F_a = 2 and k_and = 1. The second reader is an OR gate p_a = x_a ∨ z_a. We have z_a(e_a) = 0 (star.md
Lemma 3), so z_a ≰ x_a (otherwise z_a ≡ 0), and therefore p_a ∈ ∂D_a. Let q be the exit of g from the
Reader Lemma: the first node outside D_a on a path from g to the output. Then q ∈ ∂D_a is an OR gate,
and q is not a reader of x_a. So {g, p_a, q} ⊆ D_a ∪ ∂D_a, and since |D_a| + |∂D_a| <= elim <= 3,
equality holds and D_a = {g}. A reader of g is not a reader of x_a (x_a ∨ g = x_a and x_a ∧ g = g are
forbidden in a reduced circuit), and it lies in D_a ∪ ∂D_a. So the only reader of g is q =: r, and r is
an OR gate g ∨ y with y ≰ x_a (because r ∉ D_a). Finally, elim = 3 is attained by exactly these three
gates. ∎

**Corollary C2'.** In configuration (2) with F_a = F_b = 2, the second readers are distinct: p_a ≠ p_b.
In particular this holds whenever deg a = deg b = 3.
*Proof.* Suppose p_a = p_b = p. Then p = x_a ∨ x_b, and x_a, x_b are read only by g and p, which are
both symmetric in (x_a, x_b). So f_G is invariant under swapping x_a and x_b, and hence
N(a) - b = N(b) - a. Every c in this set gives a triangle abc, and two such c, c' would give the 4-cycle
a c b c'. So deg a <= 2, which contradicts deg a + δ_a >= 4. ∎

**Lemma ST (set Reader Lemma with Top; any reduced C).** Let ρ = (x_X := 0), and suppose H = G - X has
an edge. Define
* D_X = {gates p <= OR_X} (equivalently, p(1_{V-X}) = 0);
* ∂D_X = the OR gates not in D_X that have an input in D_X ∪ x_X;
* Top_X = {gates p : p|ρ = f_H}.

Then
(a) elim(ρ) >= |D_X ∪ ∂D_X ∪ Top_X| - 1 >= |D_X| + |∂D_X|;
(b) |D_X| + |∂D_X| >= |X*| + d_1, where X* is the set of non-isolated vertices of X and d_1 is the
number of gates of D_X with exactly one input in D_X ∪ x_X.

*Proof.* (a) Gates of D_X become 0. A gate of ∂D_X equals its other input, which is an earlier node.
All gates of Top_X compute f_H, so all but the earliest one, t_0, equal an earlier node. Now t_0 ∉ D_X,
because f_H ≠ 0. Also t_0 ∉ ∂D_X: otherwise its other input would be an earlier node computing f_H,
which is either an earlier Top gate or a variable, and f_H is not a variable. Every gate counted is
eliminated (t2 §0), so (a) follows. The second inequality holds because t_0 ∉ D_X ∪ ∂D_X.
(b) This is the dual of t4's Lemma R2. A node of x_{X*} ∪ D_X has a reader, since the output is not in
D_X. Every reader lies in D_X ∪ ∂D_X: an AND reader of a node that vanishes at 1_{V-X} also vanishes
there. Every gate of D_X has at least one input in D_X ∪ x_X, and every gate of ∂D_X has exactly one.
Count arcs from x_{X*} ∪ D_X by their heads: |D_X| + d_2 + |∂D_X| >= |X*| + |D_X|, where d_2 counts the
gates of D_X with two such inputs. Hence |D_X| + |∂D_X| = d_1 + d_2 + |∂D_X| >= |X*| + d_1. ∎

**Graph facts (C4-free).** need_N(a) = e(N[a]) + Δ_a, where Δ_a = tau(G) - tau(G - N[a]). N(a) induces
a matching M_a, so e(N[a]) = Σ_{c∈N(a)} deg c - |M_a| and 1 + |M_a| <= Δ_a <= deg a. Also
need_N(a) = need_B(a) + deg a, and the mixed option (N(a) → 0, a → 1) has the same need as N(a).

## 3. Reading and remaining gap

* Case (2) cannot be closed at {a, b}. On Petersen at size Phi+2, both N-options at the gate are bad.
  The deficit is 1 at each end, the first-order count is 9 and 11, and the survivors are far from
  minimal. Lemma C2 pins down the gate's neighbourhood completely when deg a = 3 (g → r, p_a, p_b), but
  the missing eliminations are elsewhere.
* The surviving local target is the analogue of t3's leaf statement: **some w ∈ N(a) ∪ N(b) - {a,b} has
  N(w) good** (DATA 785/785). Together with t3's "some w ∈ N(u) - v has N(w) good", both open cases now
  point to the same shape: an N-option at distance 1 from the bad structure.
* No proof of any N-option bound was found. need_N(w) = e(N[w]) + Δ_w is a local copy of the whole
  claim, and Lemma ST(b) gives only |N[w]| + d_1. The Top term is the right second-order quantity
  (T2-LT survives everything tested), but no lower bound for |Top| in graph terms is known.
