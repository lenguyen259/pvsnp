# L-meta-612, route T3: bad leaves and the x_a & x_b star (cases 1 and 2 of t2.md §5)

Status: **NOT closed.** The full claim for pseudoforests is still open. New results:
* **PROVED**: a generalized restriction framework (R-TOT-G, any partial 0/1 assignment);
  **Lemma N'** (any reduced circuit: elim(x_u:=0, x_v:=1) >= F_u + 2 at a leaf v); and a
  structure theorem for the bad leaves of a minimal counterexample (**Theorem L**). For pseudoforests,
  Theorem L reduces a minimal counterexample to two explicit local shapes. One of them (the *star
  shape*) is **equivalent** to the failure of a multi-output statement, Claim Z_2, which the main claim
  implies.
* **REFUTED**: every per-leaf local statement in which the good option is at v or u. The smallest
  instance has size Phi, on C5 with 3 consecutive pendants.
* **DATA**: "some w in N(u) - v has N(w) good" holds on all 17,463 locally-bad leaves. The x_a & x_b
  configuration (case 2) occurs only at size >= Phi + 2, and in all 14 instances found both N(a) and
  N(b) are good.

Labels: PROVED (full proof here), DATA (machine check only; scripts in this folder), REFUTED (explicit
circuit, checked on all 2^n inputs). Notation is that of t2.md (D_v, R_v, ∂D_v, ∂R_v, F_v, k_and,
k_or, elim, need, red). The "min cex" is a minimal counterexample as in t2 Corollary M: G is C4-free
with |V| minimum, C is a minimum circuit, s = Phi(G) - 1, and every proper induced subgraph satisfies
the claim.

## 0. Generalized options (PROVED)

**R-TOT-G.** A restriction rho is a pair (S0, S1), with x_{S0} := 0 and x_{S1} := 1, where S1 is
independent and disjoint from S0. Put F = N(S1) \ (S0 ∪ S1) and H = G - S0 - S1 - F. Then
f_G|rho = OR_F ∨ f_H. Define LB(rho) = |F| + Phi(H) if H has an edge, |F| - 1 if H is edgeless and
F ≠ ∅, and Phi(H) if F = ∅ (this requires H to have an edge). Put need(rho) = Phi(G) - LB(rho).
Framework R-TOT-F (t2.md §0) remains valid when "option" means any such rho, for a hereditary class K.

*Proof.* Edges inside S1 are absent, and an edge from S1 to w becomes the literal x_w. So
f|rho = f_{G-S0-S1, F}. Fact F of argument.md gives size >= size_min(f_H) + |F| - [H edgeless].
Then apply induction on H, which is a proper induced subgraph and so lies in K. ∎

A(v), N(v) and B(v) are the cases ({v},∅), (N[v],∅) and (∅,{v}). New here is
**N'(v) = ({u},{v})** for a leaf v with neighbour u. It has F = ∅ and H = G - u - v, so
need(N'(v)) = need(N(v)) = deg u + 1. Both values of x_v are allowed, since after x_u := 0 the
function no longer depends on x_v; we take x_v := 1. In a min cex **every** rho is bad: elim(rho) <=
need(rho) - 1. This is t2's Corollary M argument with R-TOT-G.

## 1. Case (1): bad leaves

### 1.1 Lemma N' (PROVED, any G, any reduced C)

Let v be a leaf with neighbour u, let G - {u,v} have an edge, and let x_v have an OR reader g that
does not read x_u. Then **elim(x_u:=0, x_v:=1) >= F_u + 2**. Hence N'(v) is good whenever
F_u >= deg u - 1.

*Proof.* Under rho, every gate of D_u becomes 0, every gate of ∂D_u equals its other input, every
gate of R_v becomes 1, and every gate of ∂R_v equals its other input. So all of
D_u ∪ ∂D_u ∪ R_v ∪ ∂R_v is eliminated (t2 §0). The readers of x_u lie in D_u ∪ ∂D_u (Reader Lemma).
The gate g lies in R_v and is not a reader of x_u. The output is not in R_v (f(e_v) = 0). Take the
first node q outside R_v on a path from g to the output. Then q is an AND gate whose predecessor
lies in R_v, so q ∈ ∂R_v.
* If q ∉ D_u, then q is not a reader of x_u (AND readers of x_u lie in D_u), and q ≠ g. This gives
  F_u + 2 distinct eliminated gates.
* If q ∈ D_u, continue the path from q. The output is not in D_u (G - u has an edge). The first node
  p outside D_u is an OR gate with an input in D_u, so p ∈ ∂D_u. Also p does not read x_u, because
  x_u ∨ d = x_u for d <= x_u, which reducedness forbids. Finally p ≠ g, since g < q < p on the path.
  Again F_u + 2. ∎

Since tau(G - u - v) = tau(G) - 1 (u lies in some minimum cover), need(N'(v)) = deg u + 1.
Check (`chkN.py`): 122,381 instances (the 70,452 cached circuits plus pool samples), 0 violations.

### 1.2 Theorem L: bad leaves of a minimal counterexample (PROVED)

Let G, C be a min cex, and let v be a leaf at u with d = deg u. By Corollary M, v is the unique leaf at
u, d >= 3, δ_v = 1, and x_v has a single reader g = x_v ∨ z, an OR gate. Moreover z ≠ x_u and
z ∧ x_u <= f_{G-v}. Write W = N(u) \ {v}.

**(a)** F_u <= d - 2. *(Lemma N'. G - {u,v} has an edge, since otherwise G is a star at u.)*

**(b) If d = 3:** g has exactly one reader q = g ∧ y, an AND gate. Further, y(e_u) = 1 (y >= x_u),
z(e_u) = 0, y and z do not depend on x_v, and F_u = 1.

*Proof.* B(v) is bad, so elim(x_v:=1) <= need_B(v) - 1 = d - 1 = 2. The set R_v ∪ ∂R_v is
eliminated. It contains g, and also the exit q (an AND gate) of the Reader Lemma (b). So R_v = {g}
and ∂R_v = {q}. An OR reader of g would lie in R_v. An AND reader g ∧ y lying in R_v would need
y ∈ R_v ∪ {x_v}, which is impossible. Hence q is the only reader of g.

Since x_v reaches the output only through g and then q, the circuit has the form out = H(q, ·), where
nothing else depends on x_v. Now f(e_u + e_v) = 1 and f(e_u) = 0, so q(e_u + e_v) = y(e_u) = 1 and
q(e_u) = z(e_u) ∧ y(e_u) = 0. F_u = 1 follows from (a). ∎

**(c) d = 3, and p is the single reader of x_u.** Exactly one of the following holds.
* **(star)** p = q and y = x_u, so q = x_u ∧ (x_v ∨ z). Then sing(z) = W, and q has exactly one
  reader r, an OR gate. The node z has a reader other than g, elim(x_u:=0) = 3, and the eliminated
  gates are exactly {q, r, g}.
* **(ORp)** p = x_u ∨ t is an OR gate, y lies in R_u (above p), and **t <= f_{G-u}**.

*Proof.* Suppose p is an AND gate. Then R_u = ∅, because every gate of R_u descends inside R_u to an
OR reader of x_u. Since y >= x_u, this forces y = x_u, so q reads x_u and q = p.

Next, x_u reaches the output only through q. For w ∈ W we have f(e_u + e_w) = 1 and f(e_w) = 0,
which forces q(e_u + e_w) = z(e_w) = 1. So W ⊆ sing(z), and sing(z) ⊆ W by t2's Facts.

Now consider A(u). We have need_A(u) = d + 1 = 4, since u lies in a minimum cover. Under
x_u := 0, the gate q becomes 0, every reader of q is eliminated, and g dies. If q had two readers,
or an AND reader (whose readers then die too; the output is not ≡ 0), or if z were read only by g
(so that z dies), then elim(A(u)) >= 4 and A(u) would be good. This is impossible.

Now suppose p is an OR gate. Then t does not depend on x_v, since t lies below q. If t(x) = 1, then
f(x) is the same at x_u = 0 and at x_u = 1. Setting x_v = 1 as well gives f(x, x_u = 1, x_v = 1) = 1,
so f_{G-u}(x) = 1. ∎

**(d) The star shape is equivalent to Claim Z_2 failing.** *Claim Z_k(H, W)* says: if H is C4-free,
|W| = k >= 2 and no two vertices of W have a common neighbour in H, then every circuit for f_H that
contains a node z with OR_W <= z <= OR_W ∨ f_{H-W} has >= Phi(H) + k - 1 gates.
* **The main claim implies Z_k.** Add a vertex u adjacent to W and to a new leaf v. The graph stays
  C4-free, tau rises by exactly 1, and Phi rises by k + 2. The gates g = x_v ∨ z, q = x_u ∧ g and
  out ∨ q compute f_{H+u+v}, since x_u z <= x_u(OR_W ∨ f_{H-W}) <= f.
* **A star-shape min cex gives a violation of Z_2.** It gives a *minimum* circuit
  C0 = red(C|x_u=0) for f_{G-u} (size s - 3 = Phi(G-u)) that contains z, with
  OR_W <= z <= OR_W ∨ f_{G-N[u]}. The upper bound is z ∧ x_u <= f_{G-v} read at x_u = 1. This
  violates Z_2(G - u, W). ∎

Check (`chkN.py`): every derived property holds on all instances: y >= x_u, z(e_u) = 0, sing(z) = W
in the star shape (14,302 instances), and t <= f_{G-u} in the ORp shape (10,724 instances). No other
shape occurs. DATA on Z_2 (`chkZ.py`, all cached circuits): a node of the Z-form occurs only in
circuits of size >= Phi(H) + 1 (2,600 instances, none at Phi(H)). For k = 3, none occurs at size
<= Phi + 2.

**Consequence for pseudoforests (PROVED).** In a minimal C4-free pseudoforest counterexample, every
component is a cycle C_n (n = 3 or n >= 5) with at most one pendant per vertex. At least one pendant
exists, by Theorem F2. Every pendant v at u has δ_v = 1, deg u = 3 and F_u = 1. Its leaf structure is
x_v → g → q (single readers each), and the shape at u is either star (equivalent to a violation of
Z_2 on G - u) or ORp. (The component structure is Corollary M items 1-2; the rest is Theorem L.)
The graphs allowed by the δ condition, up to 9 cycle vertices (`psun.py`), are: net = sun3; C5 with
pendants {0,1,2} or all five; C6 with {0,1}, {0,3}, {0,1,2,3} or all six; C7 with {0,1,2}, {0,1,4}, ...
The smallest beyond the net (which is checked exhaustively by SAT) have 8 vertices: C5{012}, C6{01}
and C6{03}.

Why N'(v) pays when it does: the readers of x_u, g (which becomes 1), and the exit q or p of
Lemma N'. Why it fails: F_u = 1, and then there is no further cascade. The data shows that the good
option then moves to N(w), w ∈ W. Under N(w), x_u is zeroed, so p (or q) collapses, the whole
x_v-g-q chain dies, and so do all gates of the w-star.

## 2. Case (2): minimal AND x_a & x_b with F_a, F_b >= 2

DATA (`t3star.py`, configuration: x_a & x_b a minimal AND gate, F_a, F_b >= 2, and A, B bad at both
ends):
* Fuzzing at size <= Phi + 4 (170 s per graph) found 4 instances on 2tri+bridge (sizes Phi+3,
  Phi+4) and 9 on constrS7 (Phi+3, Phi+4). At size <= Phi + 2 (70 s each, on 2tri+bridge, constrS7,
  net, C5{012}, C6{01} and C5+2p), the only instance is on C5{012}, size Phi + 2:
  `8=6|0 9=7|3 10=5&0 11=0|3 12=4&11 13=12|2 14=13&9 15=12|1 16=10|15 17=2&1 18=8|17 19=18&16 20=19|14`
  (gate 17 = x1&x2).
* In **all 14 instances both N(a) and N(b) are good**. On 2tri+bridge and constrS7, the survivors
  of N(a) form a minimum circuit of f_{G-N[a]} (for example the single gate x4&x5). That is,
  everything touching N[a] dies. The first-order bound |D_X| + |∂D_X| (X = N[a]) already reaches
  need in 26 of the 28 (instance, end) pairs. The 2 exceptions are constrS7 N(5) (7 < 10) and C5{012}
  N(2) (8 < 9), so cascades are sometimes needed.
* PROVED (from star.md, valid for reduced C): in a min cex with this configuration, ATT fails in both
  orientations (otherwise Theorem B makes A(a) good). Also
  F_a + r_h <= deg a + δ_a - 1 (Lemma 4), with the same inequality at b.
  The mixed option (x_a := 1, x_b := 0) has need = need_B(a) + 1 and gains exactly one gate (Fact F),
  so it adds nothing over B(a).
* No proof that N(a) or N(b) pays: its need is e(N[a]) + (tau(G) - tau(G - N[a])), which is 9-10
  on these graphs. That is a local version of the whole claim, and no first-order count reaches it.

## 3. Exact remaining gap

1. **Pseudoforests** reduce (PROVED) to partial suns whose pendants all have the shape of Theorem L.
   It remains to exclude:
   * (G1) the star shape, which is equivalent to violating **Claim Z_2** on G - u (DATA: no violation
     in the cache);
   * (G2) the ORp shape: p = x_u ∨ t with t <= f_{G-u}, x_v → g → q = g ∧ y, y ∈ R_u. The data
     says some N(w), w ∈ N(u) - v, pays.

   Smallest open graphs: C5{012}, C6{01} and C6{03} (8 vertices). Either "some N(w) good at a
   locally-bad leaf", or the slack form of Lemma N', would close pseudoforests.
2. Cactus graphs and subcubic graphs with leaves: Theorem L(a) holds for any deg u. For deg u >= 4,
   L(b) is not available (B(v) bad only gives elim(x_v:=1) <= deg u - 1).
3. Case (2) is DATA only (both N(a) and N(b) pay; the configuration occurs only at size >= Phi + 2).
