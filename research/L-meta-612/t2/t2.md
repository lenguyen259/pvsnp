# L-meta-612, route T2: induction on total eliminated gates

Status: **NOT closed.** New PROVED results: a first-order Reader Lemma, a Leaf Lemma, and with them
the full claim (size >= Phi = |E| + tau - 1) for **all forests** and for **all C4-free graphs whose
components are trees or cycles** (in particular all C4-free graphs of max degree <= 2). New
REFUTED: Lemma E*+ of estar/proof.md (size Phi+3), the first-order version of T2, the junk potential
"size >= Phi + #junk ANDs" on girth-5 graphs, and local (single-gate) exchange towards STAR-ALL.
New: Petersen has a non-clean circuit of size exactly Phi, so (NF5) of girth5.md fails unless the
claim fails on Petersen. Surviving target: **mANB** (§5).

Labels: PROVED (full proof here), DATA (machine check only; scripts in this folder), REFUTED
(explicit circuit, checked on all 2^n inputs).

## 0. Conventions

* C is *reduced*: no gate computes a constant, no node computes the same function as an earlier node,
  every gate reaches the output. Reducing never increases size.
* For a partial assignment rho, elim(rho) = size(C) - size(red(C|rho)), where red is functional
  reduction (constants, duplicates, dead gates). Since red keeps only non-constant first occurrences,
  **elim(rho) >= #(gates constant under rho) + #(gates equal under rho to an earlier node)**. (PROVED)
  Scripts take the better of red and red∘(rule R).
* Three options at a vertex v (need = drop of the potential):
  - A(v): x_v := 0, need_A = Phi(G) - Phi(G - v), G - v must have an edge;
  - N(v): x_{N[v]} := 0, need_N = Phi(G) - Phi(G - N[v]), G - N[v] must have an edge;
  - B(v): x_v := 1, need_B = Phi(G) - Phi_1(v), with Phi_1(v) = deg v + Phi(G - N[v]) if G - N[v] has
    an edge and deg v - 1 otherwise (Fact F of argument.md: f_G|x_v=1 = OR_{N(v)} ∨ f_{G-N[v]}).
* An option is *good* if elim >= need. T2 = "some A or N option is good"; **T2F** = "some A, N or B
  option is good".

**Framework R-TOT-F (PROVED).** Let K be a class of graphs. Suppose that for every non-star G in K with
an edge and every reduced C for f_G, some good option exists whose target (G - v, resp. G - N[v]) is in
K. Then size(C) >= Phi(G) for all G in K.
*Proof.* Induction on |V|; stars need deg + 1 inputs, hence >= deg = Phi gates. For A and N use
induction on the target. For B, the reduced restricted circuit computes f_{G-v, F} with F = N(v);
Fact F gives size >= |F| + Phi(G - N[v]) (or |F| - 1 if G - N[v] is edgeless) = Phi_1(v). So
size(C) >= need + Phi(target) = Phi(G). ∎
T2 is only needed for minimum circuits, but all tests below use all reduced circuits.

## 1. Proved lemmas

Notation: for a vertex v,
* D_v = {gates p : p <= x_v}; ∂D_v = OR gates not in D_v with an input in D_v ∪ {x_v};
* R_v = {gates p : p(e_v) = 1} (= {p >= x_v}); ∂R_v = AND gates not in R_v with an input in R_v ∪ {x_v};
* k_and, k_or = numbers of AND and OR readers of x_v; F_v = k_and + k_or.

**Reader Lemma (PROVED, any G, C reduced).**
(a) elim(x_v:=0) >= |D_v| + |∂D_v| >= F_v + min(k_and, 2), if G - v has an edge.
(b) elim(x_v:=1) >= |R_v| + |∂R_v| >= F_v + min(k_or, 2).

*Proof.* (a) Under x_v := 0 every p in D_v is constant 0, and every p = a ∨ b in ∂D_v with a in
D_v ∪ {x_v} equals the earlier node b. By the convention of §0 all of D_v ∪ ∂D_v is eliminated.
AND readers of x_v lie in D_v. OR readers x_v ∨ y lie in ∂D_v (y <= x_v would make the gate equal
x_v). So |D_v| + |∂D_v| >= F_v. The output is not in D_v (f <= x_v means G - v is edgeless).
* k_and >= 1: follow a path from an AND reader a_1 to the output; its first node q outside D_v is an
  OR gate (an AND gate with an input in D_v is in D_v), whose path-predecessor d is a gate of D_v.
  q is not a reader of x_v, since x_v ∨ d = x_v. So q is an extra element of ∂D_v.
* k_and >= 2: if D_v has a gate besides the AND readers, it is one more. Otherwise every reader of
  an AND reader a_i is outside D_v (an AND reader of a_i would be x_v ∧ a_i = a_i), hence an OR gate
  in ∂D_v that does not read x_v. If a_1, a_2 had a single common set of readers {q}, then
  q = a_1 ∨ a_2 <= x_v, so q would be in D_v. Hence there are two such exits.
(b) is the same argument with "constant 1", AND/OR swapped and R_v for D_v; the output is never in
R_v because f(e_v) = 0. ∎

The sets D_X (gates <= OR_X) and R_v give the analogous first-order bound for N(v):
elim(x_X := 0) >= |D_X| + |∂D_X|.

**Leaf Lemma (PROVED, any G that is not a star).** Let v be a leaf with neighbour u and
δ_v = tau(G) - tau(G - v). Then need_A(v) = 1 + δ_v and need_B(v) = deg u. If δ_v = 0 or deg u <= 2,
then A(v) or B(v) is good.

*Proof.* G - v and G - {u,v} have edges (G is not a star), and tau(G - {u,v}) = tau(G) - 1 (u lies in
some minimum cover), so Phi(G) - Phi_1(v) = Phi(G) - 1 - Phi(G - u - v) = deg u. F_v >= 1, since f
depends on x_v. If δ_v = 0, A(v) needs 1. If F_v >= 2 or k_and >= 1, Reader (a) gives elim >= 2 >=
need_A. Otherwise x_v has a single reader, an OR gate, and Reader (b) gives elim(x_v:=1) >= 2 >= deg u. ∎

*Facts (PROVED).* δ_v = 1 iff some minimum cover contains v, iff some minimum cover contains N(u) and
not u. If u has two leaves, every leaf at u has δ = 0 (swap both leaves for u). So the only bad leaf
is: the unique leaf at u, δ_v = 1, deg u >= 3, and x_v read by a single OR gate x_v ∨ z. In that case
z does not depend on x_v, z ∧ x_u <= f_{G-v}, and sing(z) ⊆ N(u) \ {v}.

P6 note: the P6 circuits of deg3.md with tot(leaf) = 1 are paid by B(leaf), not only by N[v]
(the neighbour of an end vertex of P6 has degree 2).

**Theorem F1 (forests). PROVED.** For every forest G with an edge, every monotone circuit for f_G has
at least |E| + tau(G) - 1 gates.

*Proof.* R-TOT-F on the class of forests (closed under deleting v and N[v]). Let G be a non-star
forest with an edge.
* A component K_{1,d} with d >= 2: its leaves have δ = 0, so the Leaf Lemma applies.
* A component K_2 = {u,v}: deg u = 1, so the Leaf Lemma applies.
* Otherwise some component has diameter >= 3. Take a longest path v_0 v_1 ... v_k (k >= 3). Every
  neighbour of v_1 other than v_2 is a leaf. If deg v_1 = 2, the Leaf Lemma applies to v_0. If
  deg v_1 >= 3, then v_1 has two leaves and δ_{v_0} = 0. ∎

**Cycle Lemma (PROVED, G C4-free with min degree >= 2 on its support, C reduced).** Some vertex v has
elim(x_v:=0) >= 3 or elim(x_v:=1) >= 4.

*Proof.* By or.md §1 (pay_core / no_module, from the accepted Lean proof L_meta_599; the circuit lemmas
are graph-free and no_module needs only min degree >= 2 and no C4), some v has ch(v) >= 2, where
ch(v) = #OR gates with an input in D_v ∪ {x_v}. Charged gates outside D_v lie in ∂D_v, and charged
gates inside D_v are OR gates of D_v. Let a_D be the number of AND gates in D_v. Then
|D_v| + |∂D_v| >= ch(v) + a_D, so a_D >= 1 gives elim(x_v:=0) >= 3. If a_D = 0, then D_v = ∅ (the
first OR gate of D_v would be x_v ∨ x_v), so the charged gates are exactly the OR readers of x_v.
Then k_or >= 2 and Reader (b) gives elim(x_v:=1) >= F_v + 2 >= 4. ∎

**Theorem F2 (trees and cycles). PROVED.** Let G be C4-free with an edge, every component of which is
a tree or a cycle (C_3 or C_n with n >= 5). Then every monotone circuit for f_G has
>= |E| + tau(G) - 1 gates. In particular this holds for every C4-free graph of max degree <= 2.

*Proof.* R-TOT-F on this class, which is closed under deleting vertices. If a component is a
nontrivial tree, use the case analysis of Theorem F1 inside that component; G is not a star, so G - v
and G - {u,v} have edges. Otherwise every nontrivial component is a cycle, and the Cycle Lemma gives
a vertex v on some cycle C_n.
* need_A(v) = 2 + 1 = 3, since tau(C_n - v) = tau(C_n) - 1.
* n >= 5: deleting N[v] removes 4 edges, and tau(C_n) - tau(P_{n-3}) = 2. So need_N = 6 and
  need_B = 6 - 2 = 4.
* n = 3: need_B = 5 - 2 = 3 if G ≠ K_3, and Phi(K_3) - Phi_1 = 4 - 1 = 3 if G = K_3.
So need_A <= 3 and need_B <= 4, and the Cycle Lemma gives a good option. ∎

Remarks.
* F1 and F2 are the first classes where the full claim (not just #OR >= |E| - 1) is proved by the
  T2 route. They use the B option (x_v := 1 plus Fact F) essentially: A alone fails on P6, C7 and
  2tri+bridge (deg3.md), and N is never needed.
* Theorems A and B of estar/star.md use only (O1)-(O3), so they hold for reduced, not only minimum,
  circuits: under their hypotheses A(a) is good. Lemma 5 does use minimality.

**Corollary M (structure of a minimal counterexample). PROVED.** Let G be a C4-free counterexample
with |V| minimum, and C a minimum circuit for f_G (so s = size(C) <= Phi(G) - 1 and every proper
induced subgraph satisfies the claim). Then:
1. every leaf v is the unique leaf at its neighbour u, deg u >= 3, δ_v = 1, and x_v has exactly one
   reader, an OR gate g = x_v ∨ z; moreover s = Phi(G) - 1 exactly and red(C|x_v=0) is a minimum
   circuit for f_{G-v} (elim(v,0) = 1, since s - 1 >= Phi(G - v) = Phi(G) - 2);
2. no component is a tree; in a pseudoforest component every leaf hangs directly on the cycle
   (a leaf at distance >= 2 from the cycle is handled by the longest-path argument of F1);
3. no leaf lies in a monomial input x_A (|A| >= 2) of the first OR gate (it would have an AND reader,
   so Reader (a) gives elim >= 2 >= need_A);
4. for every v: F_v + min(k_and, 2) <= deg v + δ_v - 1 and F_v + min(k_or, 2) <= need_B(v) - 1;
5. if G has min degree >= 2, the pay_core vertex v (ch(v) >= 2) has deg v >= 3, or deg v = 2 with
   δ_v = 1, x_v read by exactly two OR gates and by nothing else, D_v = ∅, and need_B(v) >= 5
   (so a neighbour of v has degree >= 3).
*Proof.* Each item is the contrapositive of the Leaf Lemma, Reader Lemma or Cycle Lemma, plus
R-TOT-F applied to G (a good option would give s >= Phi(G)). ∎

Readings.
* The B option is what makes T2 work at small vertices: on all data, "some vertex with A or B good"
  holds; the N option is never needed in corpus 1. deg3.md's N[v] option is a proxy for B.
* T2-LO fails: in the net circuit above, A(0) needs 2, the first-order bound gives 1, and the second
  elimination is a gate made dead or duplicate only after the first collapse. So any proof of T2 must
  count cascades (dead gates or new duplicates), not only D_X and R_v. This is exactly where junk
  enters: the cascade is the killer AND losing its job.
* The surviving statement with the most structure is **mANB** (and on corpus 1, mAB). It is the
  natural target: it localises the good vertex to a minimal AND gate, where Fact P, Lemma S and
  Theorems A/B give the structure (star, overlap, rectangle).

* constrS7, size 15 = Phi + 3:
  `7=2|3 8=2|4 9=6&5 10=9|0 11=10&4 12=11|5 13=10|8 14=1&13 15=12|14 16=6|14 17=16&7 18=3|10 19=15&18 20=17|19 21=20|14`

In both, the **only** minimal AND gate is x_a & x_b on an edge (x2&x3, resp. x5&x6), with

## 3. Route (3): exchange towards STAR-ALL (DATA; local exchange REFUTED)

Test (`exch.py`, `exch2.py`, `exch3.py`): every distinct non-STAR-ALL reduced circuit of size Phi in
the cache: **904 circuits on 9 graphs**, all with triangles (net 201, net+36 287, net+46 340, bull 15,
and 5 others). Violation count = number of AND gates violating N1, N2 or N3.

* Single-gate edits (change one gate's operation and inputs, any earlier nodes), then reduce:
  **214** circuits reach a STAR-ALL circuit of size Phi in one edit (always straight to 0 violations);
  **690 are stuck**: no single-gate edit gives a correct circuit of size <= Phi with <= as many
  violations (the plateau is empty, so BFS over plateau moves does not help either).
* Function distance to the nearest STAR-ALL minimum circuit of the same graph
  (# gate functions of C not computed anywhere in C'): 1: 203, 2: 198, 3: 2, **4: 238, 5: 49**.
  Example at distance 5 (net, 8 gates): `6=0|5 7=1|4 8=2&3 9=4|5 10=6&7 11=3|10 12=8|9 13=11&12`.
* Smallest stuck circuit: the bull [01,02,04,12,23], size Phi = 6:
  `5=0|2 6=0|3 7=2|4 8=6&7 9=1|8 10=5&9`. Gate 8 = (x0|x3)&(x2|x4) creates 02, 04, 23 and junk 34;
  gate 10 = (x0|x2)&(x1|8) creates 01, 12 and kills 34, so the triangle edge 02 does two jobs.

Conclusion. An exchange lemma, if true, cannot be local: most non-STAR-ALL minimum circuits share at
most half of their gate functions with any STAR-ALL minimum circuit. The one-for-one trade is a
rewrite of the whole star around the triangle (the rectangle gate plus the killer are replaced by two
stars), consistent with argument.md §3(e). A provable exchange would have to be stated at the level
of the "triangle template" of §3(e), not gate by gate. No such statement was found.

## 4. Junk-counting potentials (task (1))

Write j1, j2, j3 for the numbers of AND gates violating N1 (singleton carried), N2 (killer/filter)
and N3 (junk pair in the rectangle).

* On graphs with triangles, no potential of the form size >= Phi + (positive junk count) can hold:
  the net and the bull have minimum circuits with junk (argument.md §3(d), §3 above).
* **J5: for triangle-free C4-free G, size >= Phi + j3 (resp. + j1, + j2).** Corpus 1: 0 failures on
  all 20,950 triangle-free circuits (2,370 with junk), and the R-TOT step closes on all of them
  (`junk2.py`: some option X in {A(v), N(v), x_v:=1 & x_N(v):=0} has elim - need >= j3(C) - j3(C|X)).
  **But J5 is REFUTED by fuzzing** (`camp4.log`; each circuit checked on all 2^n inputs):
  - Petersen-v, size 17 = Phi + 1, j3 = 2:
    `9=1|7 10=6&9 11=3|9 12=11&2 13=5|6 14=13|3 15=0|10 16=8&14 17=5&9 18=17|4 19=1|5 20=6|7 21=18&20 22=21|12 23=19&15 24=23|16 25=24|22`
  - sun5, size 16 = Phi + 2, j3 = 3; Petersen, size 21 = Phi + 1, j3 = 2.
  - j1 survived on C5 and Petersen (100 s each); j2 fails: next item.
* **Petersen has a circuit of size exactly Phi = 20 that is not clean** (`camp4.log`, `J2` run):

      10=6|0 11=0|9 12=6|5 13=11&12 14=9|5 15=13&14 16=3|11 17=4&16 18=3|7 19=12|3 20=19&8
      21=14&7 22=1|15 23=22&10 24=23|17 25=18|1 26=2&25 27=20|26 28=27|21 29=24|28

trade (one junk rectangle saves ORs, one killer AND pays) is not confined to triangles: it also
appears in girth-5 graphs at size Phi + 1 (Pet-v) and at size Phi (Petersen).

## 5. Exact current gap

What is PROVED now: R-TOT-F (§0); the Reader, Leaf and Cycle Lemmas; the claim for forests (F1) and
for C4-free graphs whose components are trees or cycles (F2); the minimal-counterexample structure
(Corollary M). Theorems A/B of star.md hold for reduced (not only minimum) circuits.

**Open lemma (smallest form consistent with all data): mANB.** For every C4-free G with an edge that
is not a star, and every reduced circuit C for f_G, some vertex v in the support of a minimal AND
gate has one of
* A(v): elim(x_v:=0) >= Phi(G) - Phi(G - v),
* N(v): elim(x_{N[v]}:=0) >= Phi(G) - Phi(G - N[v]),
* B(v): elim(x_v:=1) >= Phi(G) - deg v - Phi(G - N[v]) (with the edgeless conventions of §0).
mANB + R-TOT-F implies the claim. It survives the cache (70,452 circuits) and fuzzing on 14 graphs;
dropping N refutes it (2tri+bridge, Phi+3), and dropping the locality to "every minimal AND gate"
refutes it (net, Phi+1). It is enough to prove it for minimum circuits of a minimal counterexample,
which by Corollary M has size Phi(G) - 1, no tree component, only "bad" leaves (unique at a vertex of
degree >= 3, δ = 1, a single OR reader), and min-degree pay_core vertices of degree >= 3 or with a
neighbour of degree >= 3.

The first open cases, in increasing difficulty:
1. **Bad leaf** (unicyclic graphs are the first class not covered): leaf v, single OR reader
   x_v ∨ z, deg u >= 3, δ_v = 1. Smallest instance with no A, N or B option good at that leaf: the spider
   [01,12,13,24,35], size Phi (corpus 1); there the good option is elsewhere.
2. **Star gate x_a & x_b with F_a, F_b >= 2** (2tri+bridge, constrS7, size Phi+3): only N(a), N(b)
   are good; no proof that N(a) pays.
3. **min degree >= 2 with the pay_core vertex of degree >= 3** (net, n8, Petersen): this is the
   general case; it requires counting cascades (T2-LO is false).
